## Catet.in 0.1.0

Rilis awal pencatat keuangan lokal untuk Android.

### Sorotan

- Ingestion notifikasi dengan allow-list sebelum isi dibaca.
- Gmail read-only dengan token terenkripsi dan sinkronisasi bertahap.
- Dedupe notifikasi/email, Review Queue, Unparsed bucket, dan audit sumber.
- Transaksi, kategori, aturan, anggaran, analitik, widget, backup/restore, dan CSV.
- Asisten lokal opsional Qwen3.5-0.8B Q4_0 dengan fallback deterministik.

### Persyaratan

- Android 8.0 (API 26) atau lebih baru.
- Native runtime `arm64-v8a` untuk fitur AI opsional.
- Gmail memerlukan OAuth client Android milik pengguna; lihat `docs/GMAIL_SETUP.md`.

### Catatan penting

- APK ditandatangani dengan keystore release Catet.in. Verifikasi sertifikat dan SHA-256 pada aset rilis sebelum memasang.
- Aplikasi belum melalui audit keamanan independen.
- OAuth Gmail live, lifecycle model Qwen, RAM 4 GB, dan perilaku OEM agresif masih perlu pengujian pada perangkat fisik.
- Fine-tuning adapter belum dijalankan; aplikasi memakai model dasar secara opsional. Detail ada di `training/README.md` dan `docs/AI_EVAL.md`.
- Backup JSON tidak dienkripsi. Simpan di lokasi aman.
