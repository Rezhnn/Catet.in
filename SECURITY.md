# Security policy

Catet.in memproses notifikasi, email, token OAuth, dan catatan keuangan di perangkat. Jangan menempelkan token, alamat email, nomor rekening, isi notifikasi nyata, atau berkas backup ke issue/PR publik.

Untuk melaporkan kerentanan, gunakan **Report a vulnerability** pada tab Security repository GitHub agar diskusinya privat. Sertakan versi APK, tipe perangkat/Android, langkah reproduksi minimal, dan dampak yang diperkirakan. Gunakan data sintetis.

Model keamanan, aset, izin, dan batasan yang diketahui dijelaskan di [docs/SECURITY.md](docs/SECURITY.md).
